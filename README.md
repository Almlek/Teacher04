# المعلّم الذكي ⭐ — دفتر التحضير الذكي

منصة ويب عربية RTL تساعد المعلمين على إنشاء خطط دروس مدرسية، اختبارات، واجبات وتقييمات.

## التشغيل
افتح `index.html` في المتصفح للتجربة المحلية. ولأفضل تجربة PWA انشر المشروع عبر GitHub Pages أو خادم HTTPS.

## المزايا الحالية
- واجهة عربية RTL متجاوبة.
- إنشاء خطة درس محليًا.
- حفظ البيانات في IndexedDB.
- إنشاء اختبار وتصحيح الأسئلة الموضوعية.
- إنشاء واجب.
- تقييم الدرس.
- طباعة الخطة.
- PWA وService Worker.
- جاهز لإضافة Backend للذكاء الاصطناعي الحقيقي.

## هيكل المشروع
`index.html` الواجهة الرئيسية، `styles.css` التصميم، `core.js` إدارة التطبيق، `db.js` التخزين، `assistant.js` محرك الخطط، `electroexam.js` الاختبارات، `homework.js` الواجبات، `evaluation.js` التقييم، `onboarding.js` البداية، `sw.js` التخزين المؤقت.

## GitHub Pages
Settings → Pages → Deploy from a branch → اختر `main` ومجلد `/root` ثم Save.

> لا تضع أي API Key داخل ملفات الواجهة أو المستودع العام.
